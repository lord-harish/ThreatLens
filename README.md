# ThreatLens

Cybersecurity Audit Intelligence & Decision Support System.

ThreatLens normalizes unstructured penetration test reports (PDF, DOCX, TXT) into an actionable vulnerability registry with blast radius mapping, CVE extraction, and evidence-grounded AI decision support.

## Key Modules
1. **Dashboard**: Executive vulnerability density, critical risk counters, severity distribution, and remediation progress.
2. **Upload Reports**: Ingestion pipeline for audit documentation with automated CVE extraction and parsing.
3. **Audit Findings**: Filterable vulnerability registry with CVSS vectors, affected asset mappings, and remediation guides.
4. **Risk Analysis**: Multi-dimensional perimeter radar, 5x5 likelihood vs impact risk matrix, priority attack paths, and recurring vulnerability tracking.
5. **AI Assistant**: Conversational decision support grounded in ingested audit evidence and NIST SP 800-53 standards.

## Technology Stack
- React 18 + Vite
- Tailwind CSS
- Recharts
- Native System Font Stack

## Quick Start

